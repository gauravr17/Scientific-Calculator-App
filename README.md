# 🧮 The Omniscience Calculator Suite

Welcome to the most powerful set of calculators ever built in a single directory. This project evolved from a simple arithmetic tool into a full-blown mathematical engine capable of handling everything from basic sums to complex linear algebra and symbolic calculus.

## 🌟 The Trio of Power

### 1. 🚀 The Omniscience Calculator (`omni.html`)
The flagship. Powered by **MathJS**, this is where the real magic happens.
- **Linear Algebra:** Determinants, Matrix Inversion, and Vector operations.
- **Calculus:** Symbolic differentiation and integration.
- **Complex Numbers:** Full support for imaginary units (e.g., $\sqrt{-1} = i$).
- **Dynamic Mode:** Toggle between Degrees and Radians on the fly.

### 2. 🧪 The Scientific Calculator (`scientific.html`)
A professional-grade tool for students and engineers.
- Advanced trigonometry, logarithms, and exponential functions.
- Clean, dark-themed UI designed for focus and efficiency.

### 3. 📱 The Simple Calculator (`index.html`)
The reliable classic. Fast, lightweight, and perfect for quick everyday calculations.

## 🛠️ Tech Stack
- **HTML5 / CSS3:** For a sleek, responsive, and modern interface.
- **JavaScript (ES6+):** Driving the logic and interactivity.
- **MathJS:** The mathematical heavy-lifter providing the symbolic engine for the Omni version.

## 🚀 How to Run
No installation required! Just open any of the `.html` files in your favorite web browser.

```bash
# Example: Open the Omniscience Calculator
open omni.html
```
